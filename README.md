# DevCloud Perú

Página estática de infraestructura cloud.

## Archivos principales

- `index.html`: estructura y contenido.
- `styles.css`: sistema visual y diseño responsive.
- `app.js`: navegación, pestañas, calculadora y generación del borrador.
- `assets/`: favicon e ilustraciones SVG.

## Vista previa local

```bash
python3 -m http.server 4173
```

Luego abre `http://127.0.0.1:4173/`.
